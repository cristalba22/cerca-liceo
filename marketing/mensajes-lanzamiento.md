## WhatsApp Para Grupos Del Barrio

Hola vecinos, soy Cristian Alba, vecino de Liceo Procrear.

Les comparto algo que estuve armando para el barrio: **Cerca Liceo**.

La idea es simple: que podamos encontrar en un solo lugar **ofertas**, comercios, emprendimientos, servicios, horarios y WhatsApp de gente del barrio.

Para el vecino es **gratis** y no hace falta registrarse para mirar. Entras, buscas lo que necesitas y escribis directo al comercio.

Para los comercios y emprendimientos tambien arranca **gratis**: pueden cargar su ficha para aparecer en la guia y publicar una promo semanal.

Lo hice porque muchas veces las ofertas se pierden en los grupos, uno no sabe quien esta abierto o donde queda cada local, y terminamos preguntando lo mismo mil veces. La idea es que esto ayude a mover mas el barrio y que los negocios chicos tengan mas visibilidad.

Pagina:
https://www.cercaliceo.com.ar/

Espero que les sirva. Cualquier consulta, necesidad o sugerencia me la pueden acercar por WhatsApp. Si tenes un local o emprendimiento y queres aparecer, escribime y te doy una mano.

Cristian Alba
Vecino de Liceo Procrear

## Post De LinkedIn

Construi **Cerca Liceo**, una app barrial real para resolver un problema concreto de mi zona.

En Liceo Procrear y alrededores muchas compras se resuelven por WhatsApp: comida de la noche, despensa, ferreteria, belleza, servicios o emprendimientos sin local. El problema es que la informacion se pierde rapido en grupos, las ofertas quedan mezcladas y el vecino termina preguntando varias veces lo mismo.

La solucion fue crear una guia hiperlocal donde:

- El vecino busca ofertas y comercios sin registrarse.
- El comercio carga su ficha gratis.
- Las promociones vencen solas para evitar informacion vieja.
- El contacto es directo por WhatsApp.
- Hay roles reales: vecino, comercio y administrador.
- El admin puede revisar, ocultar contenido y activar planes manuales.

Stack:

- React + Vite para el frontend.
- Supabase Auth, Postgres, Storage y Edge Functions.
- Cloudflare Pages con dominio propio.

Lo mas interesante del proyecto no fue solo hacer pantallas, sino pensar producto: flujos simples para comerciantes no tecnicos, soporte para emprendimientos sin direccion publica, alertas internas para revisar altas, metricas de uso y compatibilidad con celulares de gama baja.

Tambien me dejo varias decisiones tecnicas para contar:

- Por que elegi Supabase para validar rapido con backend real.
- Como modele comercios, ofertas, productos, perfiles y planes.
- Como filtre ofertas vigentes para que no queden promociones viejas.
- Como simplifique el flujo para que personas grandes puedan registrar su comercio.
- Como ajuste UI/CSS para evitar errores de renderizado en Android.

El proyecto ya esta online:
https://www.cercaliceo.com.ar/

Mas que una app de portfolio, es una prueba de producto real: problema real, usuarios reales, comercios reales y decisiones tecnicas tomadas sobre la marcha.
